# Матрица ролей и словарь терминов (role_matrix.md)

## Роли и их полномочия

### 1. Оператор (operator_a, operator_b)
**Доступные действия:**
- Создавать заявки.
- Читать собственные заявки.
- Редактировать собственные открытые заявки.

**Ограничения:**
- Не видит заявки других операторов.
- Не может назначать исполнителя.
- Не может менять статус на in_progress или resolved.

### 2. Техник (technician_a)
**Доступные действия:**
- Читать только назначенные ему заявки.
- Переводить заявки из open в in_progress.
- Переводить заявки из in_progress в resolved (с обязательным комментарием).

**Ограничения:**
- Не видит заявки, не назначенные ему.
- Не может удалять заявки.
- Не может создавать заявки.

### 3. Менеджер (manager_a)
**Доступные действия:**
- Читать все заявки.
- Назначать исполнителя.

**Ограничения:**
- Не может незаметно менять автора заявки.
- Не может менять историю действий.

### 4. Неавторизованный пользователь
**Ограничения:**
- Не может читать заявки.
- Не может создавать заявки.

## Словарь терминов

| Термин | Определение | Зачем нужен |
|---|---|---|
| **Заявка** | Запись в системе с темой, описанием, статусом и исполнителем. Имеет уникальный номер (например, LAB-104). | Основной объект работы. Оператор создаёт заявку для решения проблемы, техник выполняет работу по заявке. |
| **Номер** | Уникальный идентификатор заявки (формат LAB-XXX). Присваивается автоматически при создании. | Нужен для поиска конкретной записи в списке и карточке. Нельзя заменять номером кабинета или другим внешним идентификатором. |
| **Статус** | Текущее состояние заявки: open (открыта), in_progress (в работе), resolved (решена). | Показывает этап обработки. Оператор создаёт заявку со статусом open, техник меняет статус при работе. |
| **Вложение** | Файл (PDF или PNG), прикреплённый к заявке. Максимум 3 файла, каждый не более 5 МБ. | Позволяет приложить скриншот или документ к описанию проблемы. Пустой файл не принимается. |
| **Исполнитель** | Пользователь (техник), назначенный на заявку для выполнения работы. | Определяет, кто будет работать по заявке. Назначает менеджер. Техник видит только назначенные ему заявки. |
